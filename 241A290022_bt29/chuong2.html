Chương 2: Cấu trúc điều khiển

Phần Lý thuyết

1. Câu lệnh if - else

int diem = 8;
if (diem >= 5) {
    System.out.println("Đậu");
} else {
    System.out.println("Rớt");
}

2. Vòng lặp for

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Phần Bài tập

DễBài 1: Kiểm tra số n = 10 là chẵn hay lẻ.
Xem lời giải 
int n = 10;
if (n % 2 == 0) System.out.println("Chẵn");
else System.out.println("Lẻ");

Trung bìnhBài 2: In các số từ 1 đến 10.
Xem lời giải 
for (int i = 1; i <= 10; i++) System.out.println(i);

Khá khóBài 3: Tính tổng các số từ 1 đến 100.
Xem lời giải 
int s = 0;
for (int i = 1; i <= 100; i++) s += i;
System.out.println(s);

KhóBài 4: Kiểm tra n = 17 có phải số nguyên tố không.
Xem lời giải 
int n = 17;
boolean nt = n > 1;
for (int i = 2; i <= Math.sqrt(n); i++) {
    if (n % i == 0) { nt = false; break; }
}
System.out.println(nt ? "Số nguyên tố" : "Không phải");
