Chương 1: Làm quen với Java

Phần Lý thuyết

1. Java là gì?

Java là ngôn ngữ lập trình hướng đối tượng, chạy trên nhiều hệ điều hành nhờ máy ảo JVM.

2. Chương trình đầu tiên

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

3. Biến và kiểu dữ liệu

Kiểu Ý nghĩa Ví dụ
int Số nguyên int tuoi = 20;
double Số thực double diem = 8.5;
boolean Đúng / sai boolean dau = true;
String Chuỗi ký tự String ten = "Quý";

Phần Bài tập

DễBài 1: In ra dòng chữ "Xin chào Java".
Xem lời giải 
System.out.println("Xin chào Java");

Trung bìnhBài 2: Tính tổng hai số nguyên a = 5 và b = 7.
Xem lời giải 
int a = 5, b = 7;
System.out.println(a + b);

Khá khóBài 3: Tính chu vi và diện tích hình chữ nhật có chiều dài 8, chiều rộng 5.
Xem lời giải 
double d = 8, r = 5;
System.out.println("Chu vi: " + 2 * (d + r));
System.out.println("Diện tích: " + d * r);

KhóBài 4: Đổi nhiệt độ từ độ C sang độ F với C = 37 (F = C × 9/5 + 32).
Xem lời giải 
double c = 37;
double f = c * 9 / 5 + 32;
System.out.println(f);
